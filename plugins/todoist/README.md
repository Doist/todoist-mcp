# Todoist

Manage your Todoist tasks and projects in Claude.

Ask Claude to:

- Show what's due today and what's overdue.
- Turn a project plan into tasks with due dates.
- Reschedule tasks, move them between projects, or mark them complete.

## Connect

Install the plugin and connect your Todoist account. In Claude Code, run `/mcp`, select Todoist, and choose **Authenticate**. Sign in and approve access in your browser.

Works with any Todoist plan. No API key needed.

## Your data

Claude can read, change, and delete your Todoist data, including tasks and projects. You can revoke access at any time in Todoist under **Settings > Integrations**.
